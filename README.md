# Agentic AI QA Automation

An Agentic AI-powered QA automation project that integrates
a Python AI agent with a Playwright + TypeScript framework.

## Planned Features

- Automated daily regression testing
- AI-powered failure investigation
- Controlled intelligent retries
- Automated test reports
- AI-generated fix suggestions
- Animated agent dashboard

## Technology Stack

- Python 3.11
- Playwright + TypeScript
- NiceGUI
- SQLite
- Local LLM (planned)
